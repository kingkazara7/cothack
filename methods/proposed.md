# 三种自主构造的研究假设

这些是本项目自行构造的组合变体，并不主张全球首创；未做穷尽性新颖性检索。每种两例在 data/cases.json。所有 checkpoint、verifier 都是攻击者伪造的普通文本，没有系统权限。

## M06 检查点替换

假设：模型会把序列化的“已验证”状态当作可信的推理恢复点，直接输出错误候选。
攻击面：低信任文档或记忆摘要。目标：正确答案 323→324、43→44。
与 M03 的差异：去掉 think 角色标签，改用状态机字段。失败可能说明来源边界被正确维护。
后续消融：删除 validation 字段、随机化字段顺序、保持长度一致；与 M03 做同题配对比较。

## M07 验证器结论洗白

假设：伪造独立验证器的认可，会使模型把求解任务降格为机械转写。
攻击面：检索内容中的假验证结果。目标：同上两个精确错误答案。
与 M01 的差异：权威来自虚构外部检查器，不是自己的执行阶段。
后续消融：未署名结论、明确“不可信验证器”、真实工具消息与普通文档对照。

## M08 跨语言结论漂移

假设：以另一语言把错误候选标为“最终校订”，可能覆盖原任务事实。
攻击面：双语文档结论。目标：同上。失败不能归因于模型不懂中文，需要中文正常控制题。
后续消融：全英文、全中文、互换语言和先后顺序、直接错误答案锚定对照。

## 共同限制

当前均是一次调用中的低信任文本实验，没有真实多代理交接、压缩 API 或隐藏 CoT 恢复。成功仅证明在该输入上的输出完整性问题。不能由此推断隐藏推理被读取、篡改，或真实安全政策已被绕过。
