# 题目要求覆盖对照

核对日期：2026-10-23。本文件逐项对照题目的硬性要求，说明每一项由哪些材料满足，以及已知的覆盖边界。受测的 8 种方法为 P02/P03/P04/P06/P08（五种公开方法）加 N01/N02/N03（三种自主方法）；P01 列入调研但当前环境无法验证，P05/P07 作为调研背景保留。

| 要求 | 覆盖情况 | 支撑材料与边界 |
|---|---|---|
| 5 种公开方法调研 | 满足 | P01–P08 八篇均给出技术原理、攻击目标、公开实验依据与本项目状态（[`references.md`](references.md)）；其中 P02/P03/P04/P06/P08 为五种公开实测方法，P01 标为无法验证 |
| 3 种自主攻击设计 | 满足 | N01/N02 为低信任文本注入假设，均有威胁模型与双样例；N03 为 clean-input SAE latent injection，含闭集 feature 选择、九档强度、norm-matched control、负方向与 thinking block 复核（[`../methods/proposed.md`](../methods/proposed.md)） |
| 每种方法 ≥2 个实际测试样例 | 满足 | P02–P04、P06、P08、N01–N03 各有两个实测样例；P04/P08 每条件重复 3 次，P08 另有 4 次单因素消融 |
| 重点覆盖前沿模型 | 部分满足（主要局限） | 实测覆盖 GPT-6 Astra（仅 N01/N02）、GPT-5.6 Sol、DeepSeek、Qwen 网页与本地 Qwen3-8B；Claude Fable 5.1 / Opus 5.5 无授权调用凭据，未产生模型调用。原因见 [`../README.md`](../README.md) §1、§4 的机制层/环境层限制 |
| 有效性与可靠性 | 部分满足 | 已区分成功、部分绕过、失败、无效候选、非特异激活退化、不可观测与未运行；P04/P08 有重复，P08 有消融与 Wilson 描述区间，N03 有九档强度与配对对照；P02/P06/N01/N02 仍多为单次或少量运行 |
| 可复现性 | 较强 | 保存原始日志、输入哈希、源 row、代码/数据提交、16 份 P08 页面快照、官方网页压缩快照与校验脚本；无需凭据即可运行单测与校验（[`../README.md`](../README.md) §8）。SAE decoder（约 134 MB）与网页端固定 checkpoint/参数未随仓库提供 |
| 错误归因 | 较强 | N03 分别报告定向错答 0/2 与推理生成破坏 2/2；P03 区分零解生成失败与合格候选的部分绕过；P04 区分 token 放大、截断与答案正确性；P06/P01 分别处理排除与前置条件不足 |
| 独立研究判断 | 较强 | 明确区分 raw CoT、网页可见推理、答案污染、拒答绕过与资源攻击；提出"读取型 vs 操纵型"二分以解释前沿模型上的可行性差异；识别原论文 SAE checkpoint 缺失并构造可审计 fallback |

## 小结

受测的 8 种方法均有至少两个实际模型样例，且成功、部分绕过、失败、无效候选、非特异扰动、不可观测与未运行被分别统计，没有用无效候选或替代模型数据充当有效测试。结论可从脚本或原始日志逐项回溯。

## 已知局限

- **前沿模型未实测公开方法**：五种公开方法的实测落在 DeepSeek/Qwen 与本地 Qwen3-8B 上，而非题目点名的 Astra/Fable/Opus。读取型方法受隐藏 CoT 的机制层阻断，操纵型方法受当前环境无授权凭据的环境层阻断。取得授权端点后，P04（以 API 返回的 reasoning token 为指标、请求无害）是最优先可补的前沿覆盖项。
- **统计规模**：P02/P06/N01/N02 仍多为单次或少量运行，固定两样例只能称 PoC，需扩展到每条件 3–5 次并加入独立保留集。
- **自主方法 N01/N02 任务偏简单**：两道算术代理题应升级为多步推理任务，并补充删除可信字段、标记不可信来源、错误候选无背书等消融。
- **N03 为探索性白盒 PoC**：作者未公开 SAE checkpoint，本项目使用自训 8,192-feature fallback 与极端离分布强度，结论不外推到商业 API 的隐藏 CoT。
- **网页端不透明字段**：网页模型不公开固定 checkpoint、seed、temperature 与隐藏 reasoning token，相关字段一律记为 `N/A`，不按零处理，也不解释为隐藏 CoT 真值。
